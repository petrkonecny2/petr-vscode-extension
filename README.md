# Petr Workbench

VS Code tree of git worktrees, each with its Claude Code sessions, terminals and an "open in VS Code" entry.

Install for development:

```bash
ln -s "$PWD" ~/.vscode/extensions/petrkonecny.petr-workbench
```

Then reload the window. Open the main checkout of the repo as the workspace, or set `petrWorkbench.repoRoot`.
